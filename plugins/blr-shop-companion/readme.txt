الإضافة الرفيقة لقالب BLR Shop Pro.

== الميزات ==
* مولّد محتوى بالذكاء الاصطناعي (OpenAI / Anthropic / مخصّص) بمفتاحك الخاص.
* كاتب المنتجات داخل شاشة المنتج: وصف، مقتطف، وصف SEO، وسوم.
* مساعد تسوق للزوار يقترح منتجات حقيقية من متجرك فقط (حدّ 20 رسالة/ساعة لكل زائر).
* مولّد صفحات الهبوط الإعلانية (قالب «BLR — صفحة هبوط إعلانية»).
* أدوات محرّر المقال، واستيراد المواقع الجاهزة (يتطلب ترخيصاً).

== الإعداد ==
1. BLR Shop ← إعدادات AI ← المزوّد والمفتاح.
2. المخصّص ← المساعد الذكي (AI) ← تفعيل مساعد الزوار.
