منشئ صفحات هبوط احترافي لأي موقع ووردبريس، بالذكاء الاصطناعي.

== الميزات ==
* محرّر أقسام (16 قسماً) بمعاينة حيّة وسحب وإفلات.
* قالب Canvas مستقل عن قالب الموقع + شورتكود [blr_landing id=""] + كتلة Gutenberg.
* 7 قوالب جاهزة (3 مجانية).
* ألوان BaderLR: Aurora / Onyx / Verdant + خط المصيري + وضع ليلي.
* عملاء محتملون: نماذج آمنة، بريد، Webhook (Pro)، تصدير CSV (Pro).
* إحصاءات ونسبة تحويل، واختبار A/B (Pro).
* ذكاء اصطناعي (Pro): توليد صفحة كاملة، إعادة كتابة قسم، عناوين بديلة، SEO.
* شريط إعلان، شريط CTA ثابت، نافذة نية الخروج، عدّاد دائم، واتساب عائم.
* SEO وOG وSchema (FAQPage) وnoindex.
* تكامل ووكومرس (قسم المنتجات).

== التنصيب ==
1. ارفع الإضافة وفعّلها.
2. BLR Landing ← الإعدادات والترخيص: أدخل مفتاح الترخيص وفعّله.
3. أضف مفتاح API للذكاء الاصطناعي (Pro).
4. BLR Landing ← القوالب ← ابدأ.
