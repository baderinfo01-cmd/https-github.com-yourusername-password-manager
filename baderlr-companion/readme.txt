Tested up to: 6.6
Requires PHP: 7.4
Stable tag: 1.0.0

الإضافة الرفيقة لقالب BaderLR WP: مولّد محتوى بالذكاء الاصطناعي + استيراد مواقع جاهزة.

== الوصف ==
* مولّد محتوى بالذكاء الاصطناعي (OpenAI / Anthropic / مزوّد مخصّص) — صفحات، عناوين،
  وصف منتجات، وصف SEO، وترجمة. تستعمل مفتاح API الخاص بك.
* استيراد مواقع جاهزة بنقرة (شركة / متجر / عيادة) — ينشئ الصفحات والقائمة ويضبط الرئيسية.
* يتكامل مع ترخيص BaderLR WP (استيراد المواقع ميزة مدفوعة).

== التنصيب ==
1. الإضافات ← أضف جديد ← ارفع الملف المضغوط ← فعّل.
2. BaderLR ← إعدادات AI ← اختر المزوّد وأدخل مفتاحك.
3. BaderLR ← الذكاء الاصطناعي / المواقع الجاهزة.
