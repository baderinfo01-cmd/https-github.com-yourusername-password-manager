قالب ووردبريس احترافي مدفوع مُعزَّز بالذكاء الاصطناعي.

== الوصف ==
BaderLR WP قالب شركات من الجيل الجديد: ثلاثة أنماط تصميم (Aurora / Onyx / Verdant)،
وضع ليلي، مخصّص شامل، أنماط كتل احترافية، أنواع محتوى (خدمات/أعمال/فريق/آراء)،
WooCommerce، تحسين SEO مع Schema، وثلاث لغات مع RTL. محمي بترخيص Ed25519 مرتبط بالدومين.

يعمل مع إضافة BaderLR Companion للحصول على:
- مولّد محتوى ومواقع بالذكاء الاصطناعي (OpenAI / Anthropic / مزوّد مخصّص).
- استيراد مواقع جاهزة بنقرة.

== التنصيب ==
1. المظهر ← القوالب ← أضف جديد ← ارفع الملف المضغوط ← فعّل.
2. ثبّت إضافة BaderLR Companion المرفقة.
3. المظهر ← بدء الاستخدام، وأكمل الخطوات.
4. فعّل الترخيص من «ترخيص القالب».

== جديد في PRO 3.0.0 ==
* خط «المصيري» (El Messiri) لكل القالب والمحرّر وElementor.
* توافق Elementor: مواقع Theme Builder (رأس/تذييل/مفرد/أرشيف) تعمل مع Elementor المجاني أو Pro الذي تملك ترخيصه.
* مساعد دردشة ذكي للزوّار، وأدوات AI داخل محرّر المقال (SEO، وسوم، تحسين صياغة، أسئلة شائعة)، وإنشاء مسودة صفحة من المولّد.
* ملاحظة: القالب لا يضمّ Elementor Pro؛ ثبّته من elementor.com بترخيصك.
