# BLR Fatourati — برنامج الفوترة وإدارة الأعمال

برنامج مكتبي لويندوز (Next.js + Electron + SQLite) يعمل دون إنترنت بعد تفعيل واحد، مع ترخيص لجهاز واحد.

## الخصائص
- **المستندات:** فواتير، عروض أسعار، فواتير شكلية، سندات تسليم، إشعارات دائنة، فواتير شراء، طلبات شراء — ترقيم تلقائي، تحويل بين المستندات، فواتير متكررة تُنشأ تلقائياً.
- **الطباعة:** معاينة قبل الطباعة مع اختيار الطابعة وعدد النسخ، A4 وإيصال حراري 80مم وPDF، رمز QR، المبلغ بالكلمات (عربي/فرنسي/إنجليزي)، ثلاثة قوالب بشعارك وختمك وتوقيعك، إيصالات دفع مرقّمة (RCPT)، مشاركة واتساب/بريد.
- **أدوات:** تقويم (استحقاقات الفواتير وانتهاء عروض الأسعار والمهام)، قائمة مهام، ساعة وتاريخ في الشريط العلوي، اختصارات (Ctrl+Shift+O فاتورة جديدة، Ctrl+Shift+E عرض سعر، Ctrl+Shift+P دفعة).
- **المظهر:** 8 ألوان للبرنامج + وضع داكن، خط المصيري.
- **العملاء والموردون:** كشف حساب، رصيد، سقف دين، استيراد/تصدير Excel وCSV.
- **المنتجات والمخزون:** باركود، فئات، حد أدنى وتنبيهات، حركة المخزون (تلقائية من الفواتير)، تسوية وجرد، قيمة المخزون.
- **نقطة البيع:** مسح باركود، حساب الباقي، طباعة إيصال.
- **المالية:** دفعات جزئية، مصاريف بفئات، ديون وأعمار الديون، تقارير مبيعات/أرباح/ضريبة (TVA)/تدفق نقدي، حق الطابع الجزائري (اختياري)، عملات ونسب ضريبة قابلة للضبط.
- **الأمان:** مستخدمون وأدوار (مدير، مسؤول، أمين صندوق، محاسب)، سجل نشاط، قفل بعد محاولات خاطئة، قفل تلقائي، نسخ احتياطي يومي تلقائي ونسخ مشفّر AES-256.
- **الذكاء الاصطناعي:** تنبيهات ذكية تعمل دون إنترنت، ومساعد Claude يجيب من بياناتك (بمفتاح الزبون الخاص)، وقراءة صورة فاتورة المورد لتعبئة المصروف.
- **ثلاث لغات:** عربي (RTL) وإنجليزي وفرنسي + وضع داكن.
- **الترخيص:** مرتبط بلوحة BaderProgLicense (جهاز واحد، مدى الحياة، تجربة يومين).

## التشغيل للتطوير
```
npm install
npm run electron:dev      # يفتح البرنامج (بدون طلب ترخيص)
npm run dev               # واجهة الويب فقط في المتصفح (قاعدة بيانات تجريبية في المتصفح)
```

## الاختبارات
```
npm test                  # قاعدة البيانات (SQLite) + الحسابات + الترخيص
npm run typecheck
```

## البناء
انظر `docs/BUILD-EXE-AR.md` (ملف التثبيت) و`docs/LICENSE-AR.md` (الترخيص) و`wordpress/` (صفحة الدعاية).

## البنية
- `electron/` — العملية الرئيسية: قاعدة SQLite (`db.js`)، المستخدمون والجلسة، النسخ الاحتياطي، الطباعة/PDF، الذكاء الاصطناعي (`ai.js`)، الجسر الآمن `preload.js`.
- `bader-license/` — عميل الترخيص (Ed25519 موقّع، ربط بالجهاز والمنتج).
- `src/` — الواجهة (Next.js تصدير ثابت): `lib/` (حسابات، قالب الفاتورة، i18n)، `store/` (الحالة والمنطق)، `app/` (الصفحات).
- البيانات في `%APPDATA%\blr-invoicing\data\`. الواجهة تتعامل مع قاعدة البيانات عبر IPC فقط.
