# صفحة الدعاية لبرنامج BLR Fatourati

صفحة ثابتة (HTML/CSS/JS بلا حزم) تعرض برنامج **BLR Fatourati** (فوترة وإدارة أعمال لويندوز) بثلاث لغات: العربية، الإنجليزية، الفرنسية. تتغير لغتها من الأزرار أعلى الصفحة أو برابط `?lang=en`.

## الملفات
| الملف | الغرض |
|---|---|
| `site-config.js` | **السعر ومعلومات الاتصال والروابط واللون** — هذا ما تعدّله غالباً |
| `i18n.js` | كل نصوص الصفحة بالثلاث لغات (عدّلها لتغيير الكلام) |
| `index.html` / `app.js` | هيكل وتصميم الصفحة (لا تحتاج تعديلهما) |
| `assets/logo.png` | شعار BLR Fatourati (من `public/brand/app-icon.png`) |
| `assets/seal.png` | ختم المطوّر لإصدار التراخيص |

## تغيير السعر
افتح `site-config.js`:
```js
price: { amount: 99, oldAmount: 149, currency: "USD", period: "once", badge: {...} }
```
- `amount`: السعر الحالي — `oldAmount`: السعر قبل الخصم (ضع `0` لإخفائه)
- `currency`: `USD` أو `EUR` أو `DZD` أو `SAR`...
- `period`: `"once"` دفعة واحدة، `"year"` سنوي، `"month"` شهري
- `badge`: الشارة فوق السعر لكل لغة (اتركها `""` لإخفائها)

## تغيير معلومات الاتصال
في نفس الملف قسم `contact`: البريد، الهاتف، واتساب (أرقام فقط مع رمز الدولة)، تيليجرام، الموقع، والعنوان. **أي حقل تتركه فارغاً لا يظهر في الصفحة.**
أما `links.buy` فهو رابط زر "اشترِ الآن" و `links.download` رابط التحميل (فارغ = يُخفى الزر).

## النشر
1. ارفع مجلد `landing` كاملاً إلى موقعك (مثلاً `baderinfo.com/blr/`) عبر FTP أو لوحة الاستضافة.
2. أو للمعاينة افتح `index.html` بالمتصفح مباشرة.

## ملاحظات
- نموذج التواصل يفتح برنامج بريد الزائر برسالة جاهزة (لا يحتاج خادماً). لنموذج يرسل مباشرة اربطه بخدمة مثل Formspree.
- إن لم تكن صفحة الدفع جاهزة اجعل `links.buy` رابط صفحة طلب أو واتساب مثل `https://wa.me/213550896115`.
- الصفحة تمنع أي سكربت خارجي (CSP) ولا تحمّل شيئاً من مواقع أخرى.
- النسخة التجريبية المجانية (يومان) تُمنح بكود تجربة؛ اطلبه من المطوّر عبر واتساب أو البريد.
