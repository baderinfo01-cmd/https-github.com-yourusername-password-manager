# BLR Shop Pro

قالب متجر ووكومرس احترافي مبني **فوق قالب BaderLR WP PRO 3.0** (من الملف الذي أرسلته) مع كل ميزاته، مضافاً إليه طبقة المتجر والذكاء الاصطناعي.

| المجلد | المحتوى |
|---|---|
| `blr-shop-pro/` | القالب (مبني على BaderLR WP PRO) |
| `plugins/blr-shop-companion/` | الإضافة الرفيقة (من BaderLR Companion) + كاتب المنتجات، مساعد تسوق بسياق الكتالوج، مولّد صفحات الهبوط |
| `plugins/blr-slider-pro/` | إضافة السلايدرات المتطورة |
| `plugins/blr-landing-pro/` | **BLR Landing Pro** — إضافة صفحات هبوط مستقلة تعمل على أي موقع (Free/Pro بترخيص) |
| `promo/index.html` | صفحة إعلانية ثابتة للقالب |
| `promo/blr-landing-pro.html` | صفحة إعلانية لبيع إضافة BLR Landing Pro |
| `dist/` | حزم ZIP جاهزة للرفع |

## ما ورثه من BaderLR WP PRO
أنماط Aurora/Onyx/Verdant، الوضع الليلي، المخصّص، أنماط الكتل، أنواع المحتوى (خدمات/أعمال/فريق/آراء)، SEO وSchema، توافق Elementor، باني الرأس/التذييل، RTL وثلاث لغات، صفحة البدء، استيراد المواقع الجاهزة، ترخيص Ed25519 مرتبط بالدومين، ومساعد الدردشة.

## ما أُضيف للمتجر
- **أنواع المنتجات** (مادي · رقمي · اشتراك · خدمة) من تبويب «BLR Shop» في المنتج: شارات، نص الزر، صندوق الثقة، تفاصيل تقنية، معاينة، سجل تغييرات.
- بحث مباشر، معاينة سريعة، مفضلة، مقارنة، شريط شراء ثابت، شريط الشحن المجاني، عدّاد عروض، زر واتساب.
- رئيسية متجر جاهزة وشورتكودات `[bshop_products]` `[bshop_pricing]` `[bshop_recent]` `[bshop_countdown]`.
- **الذكاء الاصطناعي:** كاتب المنتجات، مساعد تسوق يقترح من كتالوجك فقط، ومولّد صفحات هبوط.
- **صفحة هبوط إعلانية** بقالب `BLR — صفحة هبوط إعلانية` (JSON قابل للتعديل + FAQ Schema).
- **السلايدرات:** BLR Slider Pro (4 تأثيرات، سحب باللمس، صور جوال، فيديو، عدّاد، كتلة Gutenberg).
- ديمو «متجر BLR Shop» للاستيراد.

## التثبيت
1. ثبّت ووكومرس، ثم ارفع `dist/blr-shop-pro.zip` كقالب وفعّله.
2. ثبّت `dist/blr-shop-companion.zip` و`dist/blr-slider-pro.zip` كإضافتين.
3. المظهر ← بدء الاستخدام، ثم المخصّص ← «BLR Shop — المتجر والرئيسية».
4. BLR Shop ← إعدادات AI: المزوّد والمفتاح. وفي المخصّص فعّل مساعد الزوار.

## الترخيص
نظام Ed25519 مرتبط بالدومين مع سيرفر **BaderThemesLicense**. إعدادات السيرفر (الرابط والمفتاح العام ومعرّف المنتج) **داخلية في الكود** ولا تظهر في لوحة التحكم؛ يكفي العميل إدخال مفتاح الترخيص.
- الثوابت في `functions.php` (القالب) و`blr-landing-pro.php` (الإضافة): `*_LICENSE_SERVER` و`*_LICENSE_PUBKEY` و`*_PRODUCT` (يمكن تجاوزها من `wp-config.php`).
- صفحة الترخيص: قبل التفعيل بطاقة تفعيل بمزايا واضحة، وبعده شهادة ترخيص (الاسم، رقم الترخيص، الخطة، النطاق، الصلاحية، ختم) مع تنبيه قبل الانتهاء بـ 30 يوماً.
- يلزم امتداد PHP Sodium. بدون ترخيص يعمل القالب، وتتعطل ميزة استيراد المواقع ويظهر سطر الحقوق.

> إن كانت لديك إضافة BaderLR Companion القديمة مفعّلة فعطّلها قبل تفعيل BLR Shop Companion (الإضافة الجديدة تعطّلها تلقائياً).

## الاشتراكات
القالب يتولى العرض فقط (شارة، زر «اشترك الآن»، جدول الخطط). الفوترة المتكررة تحتاج WooCommerce Subscriptions أو إضافة مكافئة.

## ملاحظات صدق
- فُحصت الشيفرة نحوياً (PHP lint / node --check) وتحققت من تعريف كل الدوال المستدعاة، **لكن لم تُجرَّب داخل ووردبريس/ووكومرس فعليين** (لا وصول للشبكة هنا). جرّبها على موقع تجريبي.
- أزلتُ خادم التراخيص الذي كنت قد بنيته سابقاً لأن قالبك يملك نظام ترخيص خاصاً به.
- صورة `screenshot.png` وشعار القالب ما زالا من BaderLR؛ استبدلهما بهويتك.

## BLR Landing Pro (إضافة مستقلة)
- محرّر 16 قسماً بمعاينة حيّة (حاسوب/تابلت/جوال)، قالب Canvas يعزل أنماط الثيم، شورتكود `[blr_landing id=""]` وكتلة Gutenberg.
- 7 قوالب (3 مجانية)، ألوان Aurora/Onyx/Verdant وخط المصيري.
- عملاء محتملون (نماذج آمنة، بريد، واتساب)، إحصاءات وتحويل.
- **Pro (بالترخيص):** ذكاء اصطناعي (صفحة كاملة، إعادة كتابة قسم، عناوين، SEO)، اختبار A/B، Webhook وتصدير CSV، كل القوالب، إزالة الشارة.
- الترخيص بنفس نظام Ed25519 وسيرفر BaderThemesLicense (المنتج `blr-landing-pro` مضبوط داخلياً): العميل يدخل مفتاحه فقط من **BLR Landing ← الإعدادات والترخيص**.
- فُحصت بمحاكاة (توليد وتنظيف وعرض كل القوالب، ولقطات شاشة، وتشغيل المحرّر في متصفح) لكن لم تُجرَّب داخل ووردبريس فعلي.
