# BLR Shop Pro

حزمة متكاملة لمتاجر ووردبريس/ووكومرس:

| المجلد | المحتوى |
|---|---|
| `blr-shop-pro/` | قالب ووردبريس (ارفعه كملف ZIP من المظهر ← قوالب) |
| `plugins/blr-slider-pro/` | إضافة السلايدرات (شورتكود `[blr_slider id=""]` + كتلة Gutenberg) |
| `plugins/blr-license-server/` | خادم التراخيص — يُثبَّت على موقع البيع فقط |
| `promo/index.html` | صفحة إعلانية ثابتة للقالب (استضفها في أي مكان) |

## التثبيت
1. ثبّت ووكومرس، ثم القالب `blr-shop-pro`، ثم إضافة `BLR Slider Pro`.
2. من **التخصيص ← BLR Shop Pro** اضبط الألوان والشريط الإعلاني وأقسام الصفحة الرئيسية.
3. أنشئ سلايدراً من **BLR Sliders ← إضافة**، وأدخل رقمه في التخصيص (أو اتركه فارغاً لأول سلايدر).
4. اجعل «الصفحة الرئيسية» صفحة ثابتة أو اتركها «آخر المقالات» (القالب يستخدم `front-page.php` في الحالتين).

## أنواع المنتجات
في تحرير المنتج ← تبويب **BLR Pro**: نوع المنتج (مادي / رقمي / اشتراك / خدمة)، تفاصيل الملف، رابط المعاينة، سجل التغييرات، وإعدادات إصدار الترخيص.
يُستنتج النوع تلقائياً إن تُرك فارغاً (قابل للتنزيل ⇐ رقمي، نوع اشتراك ⇐ اشتراك، افتراضي ⇐ خدمة).
**الاشتراكات:** القالب يتولى العرض فقط؛ الفوترة المتكررة تحتاج WooCommerce Subscriptions أو ما يكافئه.

## الذكاء الاصطناعي
**BLR Shop Pro ← الإعدادات**: اختر المزوّد (Anthropic أو متوافق مع OpenAI)، أدخل مفتاح API (يُحفظ في قاعدة بياناتك ولا يصل للمتصفح).
- **كاتب المنتجات:** صندوق جانبي في شاشة المنتج.
- **منشئ صفحات الهبوط:** صفحة جديدة بقالب «BLR — صفحة هبوط» (أو القائمة **BLR Shop Pro ← صفحة هبوط جديدة**).
- **مساعد التسوق:** يُفعَّل من الإعدادات؛ محدود 20 رسالة/ساعة للزائر وسقف يومي عام.
راجع المحتوى المولَّد دائماً قبل النشر.

## نظام الترخيص
1. ثبّت `blr-license-server` على موقع البيع وفعّله (ينشئ جداوله تلقائياً).
2. من **BLR Licenses** أنشئ تراخيص يدوياً، أو فعّل «إصدار مفتاح ترخيص» على منتج ووكومرس ليُصدر المفتاح عند اكتمال الطلب ويظهر في البريد وصفحة الطلب.
3. في موقع العميل: **BLR Shop Pro ← الإعدادات** ← ضع رابط الخادم `https://موقعك/wp-json/blr-license/v1` ثم المفتاح ← تفعيل.
4. التحديثات: ارفع ZIP الإصدار خارج مجلد الويب العام وسجّل مساره من لوحة التراخيص؛ يحصل العملاء المفعّلون على رابط تحميل موقّع مؤقت.

بدون ترخيص: القالب كله يعمل، وتُقفل ميزات الذكاء الاصطناعي والتحديثات.
> ملاحظة: القالب مرخّص GPL كما تفرض ووردبريس، لذا فحص الترخيص يحمي الخدمات والتحديثات والدعم، لا الشيفرة نفسها.

## الاختبار
لم يُختبر داخل ووردبريس فعلي في بيئة التطوير؛ فُحصت الشيفرة نحوياً (PHP lint / node --check). جرّب على موقع تجريبي قبل الإنتاج.
