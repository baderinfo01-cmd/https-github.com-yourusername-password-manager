قالب متجر احترافي لووكومرس: منتجات رقمية ومادية واشتراكات وخدمات، مبني على نظام تصميم BaderLR WP PRO.

== الوصف ==
* كل ميزات BaderLR WP PRO: ثلاثة أنماط (Aurora / Onyx / Verdant)، وضع ليلي، مخصّص شامل، أنماط كتل، CPTs، SEO وSchema، Elementor، RTL وثلاث لغات، ترخيص Ed25519 مرتبط بالدومين.
* أنواع المنتجات: تبويب «BLR Shop» في المنتج (النوع، صيغة الملف، الحجم، الإصدار، المعاينة، سجل التغييرات).
* تجربة الشراء: بحث مباشر، معاينة سريعة، مفضلة، مقارنة، شريط شراء ثابت، شحن مجاني، عدّاد عروض.
* رئيسية متجر جاهزة (سلايدر، تصنيفات، تبويبات رقمي/مادي/اشتراكات، عروض، الأكثر مبيعاً، نشرة).
* صفحة هبوط إعلانية بنّاءة (JSON) تُولَّد بالذكاء الاصطناعي.
* شورتكودات: [bshop_products] [bshop_pricing] [bshop_recent] [bshop_countdown].
* الاشتراكات: العرض والتجربة من القالب؛ الفوترة المتكررة عبر WooCommerce Subscriptions أو مكافئ.

يعمل مع: BLR Shop Companion (الذكاء الاصطناعي واستيراد المواقع) وBLR Slider Pro (السلايدرات).

== التنصيب ==
1. المظهر ← القوالب ← أضف جديد ← ارفع الملف ← فعّل. ثبّت ووكومرس.
2. ثبّت BLR Shop Companion وBLR Slider Pro.
3. المظهر ← بدء الاستخدام.
4. فعّل الترخيص من «ترخيص القالب» (أنشئ المنتج blr-shop-pro في سيرفر BaderThemesLicense).
