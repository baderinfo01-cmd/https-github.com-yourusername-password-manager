## التشغيل خطوة بخطوة

### 1) المتطلبات (مرة واحدة)
1. ثبّت **Node.js 22 أو أحدث** من https://nodejs.org (يشمل npm).
2. افتح الطرفية (CMD أو PowerShell) داخل مجلد المشروع.

### 2) تثبيت الحزم
```
npm install
```

### 3) التشغيل للتطوير
```
npm run electron:dev
```
ينتظر الأمر تشغيل الخادم على المنفذ 3000 ثم يفتح نافذة البرنامج. (للمتصفح فقط: `npm run dev` ثم افتح http://localhost:3000/ar — مميزات الذكاء الاصطناعي تعمل في نسخة سطح المكتب فقط.)

### 4) أول استخدام
1. تظهر نافذة **تفعيل الترخيص** (إن لم يكن البرنامج مفعّلاً): أدخل كود التفعيل. (في وضع التطوير يتم تجاوزها تلقائياً.)
2. تظهر شاشة **إنشاء كلمة المرور الرئيسية**: اختر كلمة من **8 أحرف على الأقل** فيها حروف وأرقام، وأعد كتابتها.
   - ⚠️ لا يوجد استرجاع للكلمة. إن نسيتها فُقدت البيانات (هذا هو ثمن التشفير الحقيقي). احتفظ بنسخة احتياطية (الإعدادات ← النسخ الاحتياطي) وبكلمة المرور في مكان آمن.
   - إن كانت لديك بيانات من نسخة قديمة، ستُشفَّر تلقائياً بالكلمة الجديدة وتُحذف النسخة غير المشفّرة.
3. أكمل **إعداد الملف الشخصي** (الاسم، البريد ...).
4. تصل إلى لوحة التحكم.

### 5) الاستخدام اليومي
- **فتح البرنامج:** أدخل كلمة المرور الرئيسية. الخاطئة تُرفض، وبعد 3 محاولات تنتظر قليلاً.
- **القائمة الجانبية:** حسابي، البطاقات، الوثائق، جهات الاتصال، الحسابات، الاشتراكات، **المساعد الذكي**، مولّد كلمات المرور، التحليلات، الإعدادات.
- **القفل:** زر **قفل البرنامج** أسفل القائمة، أو تلقائياً بعد الخمول (الإعدادات ← الأمان ← القفل التلقائي).
- **تغيير كلمة المرور:** الإعدادات ← الأمان ← تغيير كلمة المرور الرئيسية ← أدخل الحالية والجديدة.
- **حذف كل البيانات / استعادة الافتراضي:** الإعدادات ← المنطقة الخطرة، ويطلب كلمة المرور.

### 6) المساعد الذكي
1. افتح **المساعد الذكي** من القائمة.
2. في الأعلى ترى **درجة أمان الخزنة** وقائمة الحسابات الضعيفة/المكررة/القديمة، وهذا يعمل **محلياً بالكامل** بلا إنترنت.
3. لاستخدام المساعد التفاعلي: أنشئ مفتاحاً من https://console.anthropic.com والصقه في الحقل واضغط **حفظ المفتاح** (يُحفظ مشفّراً داخل الخزنة).
4. اختر سؤالاً جاهزاً أو اكتب سؤالك.
5. **الخصوصية:** يُرسَل فقط ملخص (أسماء المواقع وتصنيف المشكلة). لا تُرسَل كلمات المرور ولا بيانات البطاقات ولا الوثائق.

### 7) بناء ملف التثبيت (.exe)
```
npm run dist
```
يظهر الملف داخل مجلد `dist/`. ثبّته ثم شغّله من سطح المكتب.

### 8) الاختبارات
```
npm run typecheck   # فحص TypeScript
npm test            # اختبارات التشفير والقفل
```

## ملاحظات أمنية صادقة
- التشفير يحمي بياناتك من أي شخص يفتح ملفات الجهاز دون كلمة المرور. كلمة مرور ضعيفة تبقى أضعف نقطة، فاختر كلمة طويلة.
- ملفات النسخ الاحتياطي (تصدير JSON) **غير مشفّرة**؛ احفظها في مكان آمن أو احذفها بعد الاستخدام.
- برنامج خبيث يعمل على جهازك أثناء كون البرنامج مفتوحاً يمكنه قراءة الذاكرة، لذا استخدم القفل عند الابتعاد.
