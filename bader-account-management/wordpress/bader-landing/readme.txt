Multilingual (Arabic / English / French) sales page for Bader Account Management. Add the shortcode [bader_landing] to any page.

== Description ==
Add [bader_landing] to a page. Edit price, trial length and contact details under Settings > Bader Landing.
Optional: [bader_landing lang="en"] forces a language.
