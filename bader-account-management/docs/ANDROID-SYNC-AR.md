# المرحلة الثانية: تطبيق الأندرويد + المزامنة مع الكمبيوتر + إشعارات الدخول

## ماذا أصبح عندك؟
| الميزة | الحالة |
|---|---|
| **تطبيق أندرويد** (نفس البرنامج بنفس المظهر، بالعربية/English/Français) | ✅ نسخة **PWA** جاهزة للتثبيت (تعمل الآن) + مشروع **APK** (Capacitor) يُبنى عبر GitHub |
| **مزامنة الكمبيوتر ↔ الهاتف** (كل تعديل في الطرفين) | ✅ مشفّرة من طرف إلى طرف، عبر خادم PHP صغير على استضافتك |
| **إشعارات الدخول** (وقت، جهاز، نظام، IP، الموقع التقريبي، محاولات فاشلة) | ✅ على الجهازين، وتصل **حتى والخزنة مقفلة** |
| **سجل الأمان** | ✅ صفحة «سجل الأمان» في القائمة |

> ما اختبرته فعلاً: المزامنة والتنبيهات بين «كمبيوتر» و«هاتف» (متصفحان حقيقيان) مع خادم PHP حقيقي، وتشغيل واجهة الهاتف، والعمل دون إنترنت (PWA)، ومنطق قشرة الأندرويد على خادم يحاكي Capacitor. **ما لم أستطع اختباره هنا:** بناء ملف APK وتشغيله على جهاز حقيقي (بيئتي بلا Android SDK)، لذلك أضفت **مسار GitHub لبناء الـAPK** وجرّبه على هاتفك أولاً.

## الخطوة 1 — رفع خادم المزامنة إلى استضافتك (10 دقائق)
خادم صغير يحفظ **بيانات مشفّرة لا يقرؤها أحد** (لا أنت ولا الاستضافة). متطلباته: PHP 7.4+ مع `pdo_sqlite` (متوفر في معظم الاستضافات) و**HTTPS**.

1. على موقعك أنشئ مجلداً: `public_html/bader-sync/`
2. ارفع إليه محتويات مجلد `sync-server/` (الملفات `api.php` و`config.sample.php` و`.htaccess` ومجلد `data/`).
3. انسخ `config.sample.php` باسم **`config.php`** وعدّل:
   ```php
   'register_key' => 'اكتب-هنا-نصاً-طويلاً-عشوائياً',   // مفتاح لا يعرفه غيرك
   ```
   (هذا المفتاح يمنع الغرباء من استعمال مساحة استضافتك.)
4. تأكد أن مجلد `data/` قابل للكتابة (صلاحية 755 أو 775).
5. اختبر: افتح `https://baderinfo.com/bader-sync/api.php` في المتصفح. إن ظهر `{"ok":false,"error":"method_not_allowed"}` فالخادم يعمل ✅.

## الخطوة 2 — على الكمبيوتر: أنشئ حساب المزامنة
1. افتح البرنامج ← **المزامنة** (من القائمة).
2. «**① الجهاز الأول**»: عنوان الخادم `https://baderinfo.com/bader-sync/api.php`، ومفتاح التسجيل (نفسه في `config.php`)، ثم **إنشاء حساب المزامنة**.
3. تظهر حالة «متصل». اضغط **إظهار** تحت «رمز الربط» فيظهر **نص طويل يبدأ بـ `BSYNC1:`** و**رمز QR**.

> ⚠️ رمز الربط = مفتاح فك تشفير كل بياناتك. لا ترسله ولا تنشره. استعمله لربط أجهزتك فقط.

## الخطوة 3 — على الهاتف: ثبّت التطبيق
### الطريقة (أ): تطبيق ويب PWA (الأسرع، تعمل الآن)
1. أنشئ نطاقاً فرعياً مثل **`app.baderinfo.com`** (يجب أن يكون في **جذر** نطاق/نطاق فرعي، لا داخل مجلد).
2. على الكمبيوتر نفّذ `npm run build` ثم ارفع **محتويات** مجلد `out/` إلى مجلد ذلك النطاق الفرعي.
3. افتح `https://app.baderinfo.com` في **Chrome على الأندرويد** ← قائمة ⋮ ← **«تثبيت التطبيق»** (أو «إضافة إلى الشاشة الرئيسية»).
4. يظهر كتطبيق بأيقونتك، يفتح بملء الشاشة، ويعمل **دون إنترنت** بعد أول تحميل.

### الطريقة (ب): ملف APK حقيقي (بلا Android Studio)
1. ارفع المشروع إلى مستودعك على GitHub (موجود أصلاً).
2. على GitHub: تبويب **Actions** ← **Build Android APK** ← **Run workflow**.
3. بعد 5–10 دقائق افتح التشغيل الناجح ← أسفل الصفحة **Artifacts** ← حمّل `bader-account-management-apk` وفك الضغط.
4. انسخ `app-debug.apk` للهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

أو بنفسك على جهازك (يتطلب Android Studio):
```
npm run build
npx cap sync android
npx cap open android      # ثم Build > Build APK
```
**ميزات أمان في نسخة الأندرويد:** منع لقطات الشاشة وتسجيل الشاشة، منع النسخ الاحتياطي التلقائي لبيانات التطبيق (`allowBackup=false`)، لا حركة غير مشفّرة.
للنشر على **Google Play** تحتاج توقيع Release بمفتاح خاص بك (keystore) وحساب مطوّر؛ اسألني وأجهّز لك الخطوات.

## الخطوة 4 — اربط الهاتف
1. افتح التطبيق على الهاتف، أنشئ **كلمة مرور رئيسية** (يمكن أن تختلف عن الكمبيوتر).
2. القائمة ☰ ← **المزامنة** ← «**② جهاز آخر**».
3. الصق رمز الربط (أو اضغط «مسح QR» ووجّه الكاميرا لشاشة الكمبيوتر) ← **ربط هذا الجهاز**.
4. تظهر بياناتك في الهاتف خلال ثوانٍ. من الآن: أي تعديل في أي جهاز يصل للآخر خلال **≈ دقيقة** (أو فوراً بزر «زامن الآن»).

## الإشعارات (تسجيل الدخول)
- عند **كل دخول** (ناجح أو فاشل) على أي جهاز، يُرسَل تنبيه مشفّر يضم: **الوقت، اسم الجهاز، النظام، عنوان IP، الموقع التقريبي** (مدينة/دولة).
- يصل التنبيه إلى **الأجهزة الأخرى** كإشعار نظام + نافذة داخل البرنامج، ويُسجَّل في «سجل الأمان».
- يعمل **حتى والخزنة مقفلة** لأن للتنبيهات مفتاحاً منفصلاً **لا يستطيع فك بياناتك** أبداً.
- فعّل الإشعارات من صفحة **المزامنة ← تفعيل الإشعارات** (يطلب الإذن مرة واحدة).
- الموقع التقريبي يُحدَّد من عنوان IP عبر خدمة `ipwho.is` (يُرسَل لها عنوان IP فقط). يمكنك **تعطيله** من «سجل الأمان».
- بعد الدخول يُعرض لك ملخص: «تسجيل دخول جديد… وفشلت N محاولات منذ آخر دخول».

**حدّ صريح:** التنبيه يصل بينما تطبيق الطرف الآخر **مفتوح أو يعمل في الخلفية** (يفحص كل 45 ثانية). إن كان التطبيق مغلقاً تماماً على الهاتف فلن يصل إلا عند فتحه، لأن الإشعارات الفورية الحقيقية (Push) تحتاج حساب Firebase (FCM). هذه خطوة ممكنة لاحقاً إن أردتها.

## كيف تعمل المزامنة وأمانها
- **تشفير من طرف إلى طرف (AES-256-GCM):** مفتاح المزامنة يُولَّد على جهازك ولا يغادر أجهزتك. الخادم يرى فقط بيانات مشفّرة ومعرّفات مموّهة. اختبرتُ أن قاعدة بيانات الخادم **لا تحتوي أي نص مقروء** (لا أسماء مواقع ولا كلمات مرور ولا هواتف).
- **ما الذي يُزامَن:** الحسابات، الاشتراكات، البطاقات، الوثائق، جهات الاتصال، التصنيفات، معلوماتي، وكلمات المرور المولَّدة.
- **ما لا يُزامَن:** كلمة المرور الرئيسية (لا تُخزَّن أصلاً)، مفتاح الذكاء الاصطناعي، الإعدادات الشخصية (القفل التلقائي، اللون).
- **التعارض:** إن عُدّل العنصر نفسه على جهازين قبل المزامنة **يفوز الأحدث** (حسب ساعة الجهاز، فاحرص أن تكون ساعتا الجهازين صحيحتين). الحذف ينتقل للجهاز الآخر.
- **جهاز جديد يرتبط بحساب فيه بيانات:** بياناته الافتراضية (ملف شخصي فارغ، تصنيفات افتراضية) **لا تمسح** بياناتك الموجودة؛ تُدمج.
- زر «حذف كل البيانات» **لا ينتقل** للأجهزة الأخرى (يفك الارتباط محلياً أولاً).
- حماية الخادم: تحديد محاولات الدخول، حدّ لعدد الحسابات والحجم، ورفض أي طلب بلا رمز صحيح.

### إن ضاع هاتفك
«فك الارتباط» على هاتف ضائع لا يلغي مفتاحه. الإجراء الآمن: (1) غيّر كلمة المرور الرئيسية على الكمبيوتر (2) على الخادم احذف الملف `data/sync.sqlite` (يمسح كل حسابات المزامنة) (3) أنشئ حساب مزامنة جديداً واربط أجهزتك من جديد. (قفل الهاتف بكلمة المرور الرئيسية يحمي بياناته المحلية أصلاً.)

## حل المشاكل
| المشكلة | الحل |
|---|---|
| «مفتاح التسجيل غير صحيح» | يطابق `register_key` في `config.php` على الخادم |
| «تعذّر الاتصال بالخادم» | العنوان خاطئ أو لا HTTPS أو الاستضافة تحجب الطلب. اختبر `api.php` في المتصفح |
| «رمز الربط غير صحيح» | انسخه كاملاً (يبدأ بـ BSYNC1:) من حساب المزامنة نفسه |
| لا تصل الإشعارات | فعّل الإشعارات في صفحة المزامنة، وافتح التطبيق على الجهازين |
| تعديل لم يصل | اضغط «زامن الآن»، وتأكد أن ساعتي الجهازين صحيحتان |
| `data_dir_not_writable` | اجعل مجلد `data/` على الخادم قابلاً للكتابة (755/775) |
| الـ APK لا يُبنى على GitHub | أرسل لي نص الخطأ من صفحة التشغيل |
