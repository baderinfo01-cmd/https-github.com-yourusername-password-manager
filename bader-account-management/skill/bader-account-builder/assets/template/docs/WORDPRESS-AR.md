# صفحة بيع البرنامج على ووردبريس — شرح خطوة بخطوة

الإضافة (Plugin) اسمها **Template App Landing**: صفحة إعلانية احترافية بثلاث لغات (العربية / English / Français) تذكر كل خصائص البرنامج وأهميته وحمايته، مع **تغيير السعر ومعلومات الاتصال من لوحة ووردبريس** دون لمس أي كود.

الملف الجاهز للرفع: `wordpress/template-app-landing.zip`

## 1) التثبيت
1. ادخل لوحة ووردبريس ← **إضافات (Plugins) ← أضف جديد ← رفع إضافة (Upload Plugin)**.
2. اختر `template-app-landing.zip` ← **تثبيت** ← **تفعيل**.

## 2) أنشئ الصفحة
1. **صفحات ← أضف جديد**، عنوانها مثلاً "برنامج Template App".
2. في المحرر أضف كتلة **«رمز قصير» (Shortcode)** والصق فيها: `[template_app_landing]`
3. **انشر**.
4. لأفضل مظهر: في إعدادات الصفحة اختر قالب **«عرض كامل» / «Canvas»** (إن وفّره قالبك)، أو فعّل خيار **عرض كامل** في إعدادات الإضافة (القسم 4).

لغة محددة لصفحة معينة: `[template_app_landing lang="en"]` أو `lang="fr"` أو `lang="ar"`.

## 3) غيّر السعر ومعلومات الاتصال
من لوحة ووردبريس: **إعدادات ← Template App Landing**

| الحقل | الوظيفة |
|---|---|
| السعر الحالي / قبل الخصم | مثال: 49 و 79 (ضع 0 في "قبل الخصم" لإخفائه) |
| رمز العملة | `USD` `EUR` `DZD` `SAR` `MAD` `EGP` `AED`... (يُعرض بالرمز المناسب لكل لغة) |
| نوع الدفع | دفعة واحدة مدى الحياة / سنوي / شهري |
| شارة العرض | مثل "عرض الإطلاق" لكل لغة |
| إظهار زر التجربة + مدة التجربة | يظهر زر "جرّب مجاناً يومين" (غيّر الأيام كما تشاء) |
| رابط طلب التجربة | اختياري؛ إن تُرك فارغاً يُستعمل واتساب ثم البريد |
| رابط الشراء / التحميل | أزرار الصفحة (التحميل يُخفى إن تُرك فارغاً) |
| البريد، الهاتف، واتساب، تيليجرام، الموقع، العنوان | **أي حقل فارغ لا يظهر في الصفحة** |
| اللون الرئيسي | لون أزرار وعناصر الصفحة |
| اللغة الافتراضية | تلقائي (حسب لغة الموقع) أو لغة محددة |
| تخصيص العنوان والوصف | اختياري لكل لغة |

اضغط **حفظ التغييرات** ثم حدّث الصفحة. (إن كان عندك إضافة كاش، امسح الكاش.)

## 4) كيف يرى الزائر اللغات؟
أزرار **العربية / English / Français** أعلى الصفحة. يتبدل النص والاتجاه (يمين-يسار أو العكس) فوراً دون إعادة تحميل، ويتذكر المتصفح اختياره.

## 5) تعديل النصوص
كل نصوص الصفحة (المزايا، الأمان، الأسئلة...) في ملف واحد داخل الإضافة: `includes/strings.php` بالثلاث لغات. عدّل النص وأبقِ المفاتيح كما هي. (مثلاً: `{days}` تُستبدل تلقائياً بمدة التجربة.)

## 6) ما تحتويه الصفحة
شريط تنقل ولغات ← الواجهة الرئيسية وأزرار الشراء والتجربة ← **لماذا تحتاجه** ← **كل المزايا (12)** ← **الأمان (8 نقاط)** ← **المساعد الذكي** ← **كيف يعمل الترخيص (3 خطوات)** ← **السعر** ← **أسئلة شائعة** ← **تواصل** ← دعوة أخيرة. وتضيف بيانات SEO (Schema.org) للسعر.

## 7) أمان الإضافة
- كل مدخلات الإعدادات تُنقّى عند الحفظ (روابط، أرقام، ألوان...) وتُهرَّب عند العرض، ويُرفض أي رابط `javascript:`.
- لا تحمّل أي ملف من مواقع خارجية، ولا ترسل بيانات الزوار لأي جهة.
- صلاحية تعديل الإعدادات لمن يملك `manage_options` (المدير) فقط.

## 8) إن لم يكن موقعك ووردبريس
استعمل النسخة المستقلة في مجلد `landing/` (انظر `landing/README-AR.md`).

## ملاحظات
- لم تُجرَّب هذه الإضافة داخل ووردبريس حقيقي بعد (فحص صياغة PHP فقط)، فجرّبها على موقع تجريبي أولاً.
- لا تحتوي الصفحة على آراء زبائن أو أرقام مبيعات مختلقة. أضف إن شئت آراء حقيقية فقط.
